# Campus Tour owner instructions

This repository owns the campus application, photographs, placements, branding,
optional YouVisit importer, accessible content, release tooling and retained
content/docs/research. The club landing page and final assembly belong to
`UMN-VR/UMN-VR.github.io`; campus About content and release graph adaptation to
`UMN-VR/about`; the workspace wrapper to `UMN-VR/dev_installer`.

Use the independent FOSS Earth providers through public exports. Earth website
wrappers, including `foss-earth` and `foss-earth/vite`, are excluded from final
Campus adoption. Runtime/UI/renderer/toolbar/scenes/360/images and representation
packages have their own repositories. Preparation and checking use exported package tools, never copied
implementations or deep checkout imports. Request missing contracts from Earth
through the sole Campus coordination handoff; never edit its checkout.

You cannot have AI as a co-author, or your contributions will be rejected.

Preserve human author/committer metadata, asset credits, licenses, dirty work and
all ignored evidence. Scratch belongs in `.local/`. The original application
archive is read-only, including the private YouVisit backup; never discover,
move, copy or delete that backup. Only the assigned sole Campus scratch handoff
is writable there. Generated content is an exact input, not a regeneration step
in normal setup. Optional authoring requires explicit `--backup` authorization.

Preserve current routes, thirteen tab IDs, report-only behavior, worker scope,
update behavior, older resources and accessible content. Do not claim future
accessibility/media work is complete. Search/VR remain deferred; no new current
tab IDs or required dependencies. Runtime/build/setup have no flight dependency.

A camera move follows the shared engine's momentum rules: no abrupt jump, user
input acts immediately, interrupted movement continues from its current state.
The host renders on demand; a change requests rendering once when ready and
creates no independent loop. Dropdown width follows its text/options, not its
row. Generic camera/render/input/layout changes belong to their Earth owners.

The primary alone writes current composition, manifests, locks and accepted
child artifacts. Record any new child scope before writes. Reserve the shared
machine check slot through the handoff; no install, module execution, tests,
typecheck, lint, build, pack, browser/native/media or benchmark while queued.
For a granted stable candidate, run relevant type/related tests/lint and one
finished owner CI, cap workers at half cores, and retain exact logs/receipts.
Never infer a slot from another owner's release. No implicit servers or deploys.

Every owned repo uses the same immutable shared CI policy/caller/blob with no
docs/content path skip. Old receipts retain their original byte/policy scope.
Report exact conformance/full-ref results and remote gates to the coordinator;
local source pins are not a hosted admission or publication receipt.
