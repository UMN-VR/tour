# Tour selector

`index.html` is the static selection page published at `/tour/`. It links to the
three independently authored routes with ordinary HTML anchors:

- `/tour/minneapolis/`
- `/tour/st-paul/`
- `/tour/twin-cities/`

The page does not load a campus App, construct a viewer, or require JavaScript.
`src/selector.css` provides the shared maroon/gold presentation, responsive cards,
visible keyboard focus, and a skip link. Link labels and descriptions remain in
HTML; images have descriptive alternatives, and the decorative arrow is hidden
from accessibility APIs. There are no animations or motion transitions. These
are source properties; browser, keyboard, zoom, and assistive-technology
qualification remain queued under the coordinator's bounded check grant.

## Image references and rights

public URLs. It copies no photographs and makes no dependency on either scene
checkout or the private authoring backup. The club assembly must retain those
compatibility resources from the single hash-pinned prepared-media release;
their legacy route is a URL base, not a package dependency on the Twin Cities
aggregate. Measuring and sealing that release remains a later granted phase.
